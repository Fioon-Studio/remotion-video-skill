# 给自己做账号专属款

开源款保留可移植的方法、通用模板和示例配置。品牌角色、Logo、配音、截图、字体授权文件、资产路径与账号节奏应保存在本机私有项目，不进入公开仓库。

如果你已经有一个正在使用的 Remotion 项目，先为它创建一份私有配置，而不是再复制一个新项目。私有配置至少需要记录：

- 现有项目入口和正在使用的 Composition
- 已确认的 Logo、角色母版、行走帧、字体、BGM、音效和截图目录
- 每条视频的脚本、最终配音、`timing.json` 与 `asset-map.json` 的位置
- 章节进度条、画框、白底/黑底场景、字幕断句、截图聚焦和审片规则

不要把绝对路径、账号密钥、个人录音、浏览器资料、客户截图或自有角色素材写进此仓库。公开项目只需要告诉使用者“在自己的私有配置中维护这些内容”。
