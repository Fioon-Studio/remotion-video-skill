# 可直接复用的画面实现

复制模板中的 `src/VideoSystem.tsx`，再把素材和品牌配置替换进去。它不依赖任何预置品牌文件。

## 进度条与小人

- `ProgressRail` 的章节位置由 `at: 0` 到 `1` 定义；`at` 应对应章节在完整配音中的真实相对位置。
- 已走过的线段和节点使用 `accent`，未到达部分使用低对比灰色。
- 默认 `WalkingMascot` 是 SVG 占位小人，腿、手和上下起伏都由当前帧驱动，循环不会跳帧。
- `gaitFramesPerCycle` 决定步频，默认 32 帧一循环。不要因为章节很长就加快步频；横向移动已经由真实章节帧控制，步频只负责自然的行走节奏。
- 换成自己的角色时，准备透明底、同尺寸、同视角的 4 到 8 帧行走图。第一帧和最后一帧姿态必须自然衔接；在 `ProgressRail` 中按 `frame % frameCount` 切换，不要把不同角度的整张人物图硬切。
- 直线的垂直中心必须与每个圆点的垂直中心完全重合。模板使用 `top: 13px; height: 2px` 的线和 `top: 8px; height: 12px` 的圆点，两者中心都在 `14px`。
- 进度条只放在顶部导航区。角色整个身体在进度线的上方移动，脚底贴在线上或略高于线；不穿过线、不压章节文字。默认 SVG 小人的 `top` 已按脚底位置计算，替换角色帧时也按脚底基线定位。

## 白底场景

- 使用 `WhiteSceneFrame`。画框处于顶部进度条和底部字幕之间的主体区，不贴画布上缘。
- 画框宽约 82%、高约 61%，圆角和外框在 1080p 下分别约 34px、5px；竖版按画布比例缩放。
- 人物、截图和文字的总视觉重量以主体区中心为准。左右分屏时，图像与文字组的总面积、留白和重心要平衡。
- 图片内只有 1 到 3 个短重点时才加字，并放在干净留白处。超过 3 项，切到黑底卡。
- 同一白底段超过约 5 秒时，准备同机位、同场景的 3 个连续动作帧，并用口播里的动作、结果或转折作为切换锚点。不要只靠缓慢缩放撑时长。
- 固定片头不直接套白底场景：先用黑底网格交代标题与章节总览，等黄金三秒说完再进入第一张白底例子。

## 黑底知识卡、点亮和聚焦

- 黑底网格必须是最底层背景。普通步骤、文件夹和选项保持原位，口播讲到对应词时才点亮，其他项只轻微变暗。
- `ScreenshotFocus` 只用于一个文件、按钮、README 段落或截图区域。框选目标应在可见裁切区域的中心，四周界面变暗；不要让普通列表逐项跑到中间。
- 点亮的开始帧和结束帧都读取 timing manifest 中该词的 `startFrame` / `endFrame`，不得把场景时间平均切分。当前项固定按下面方法判定：

```ts
const isSpeaking = (frame: number, cue: VisualCue) =>
  frame >= cue.startFrame && frame < cue.endFrame;
```

只在 `isSpeaking` 为真时使用亮态；词说完立即暗下。60fps 每帧约 16.7ms，因此把强制对齐的毫秒时间换算到最近一帧，不额外追加动画延迟。

## 字幕渐变与稳定位置

- 通过 `GradientCaption` 让整句在 7 帧内淡入并轻微上移。字幕始终固定在字幕区，不跟随不同画面上下跳动。
- 先按逗号、句号、问号、感叹号和自然停顿分句，显示时去掉 `，。？！`。不要拆开词语，也不要用每两个字一张字幕卡的做法。
- 字幕、配音和画面 cue 必须来自同一份真实音频 timing manifest。重新生成 TTS 后，三者一起重算。

## 背景与素材预设

| 内容 | 预设 | 素材要求 |
| --- | --- | --- |
| 生活例子、人物讲解、产品结果 | `paper` + `WhiteSceneFrame` | 1K 图片即可；人物和场景同图，背景留出文字区 |
| 四项以上、关系、定义、流程 | `grid` | React/SVG 文本和图形，当前项点亮 |
| 真实软件操作 | `ScreenshotFocus` | 只裁切任务相关区域；必要时框选后局部放大 |
| 代码或命令 | `grid` + typewriter | 使用终端框和逐字输入，保证命令完整可读 |

## 预览顺序

每个场景至少看三帧：口播词出现前、词出现的首帧、下一条 cue 出现后。重点检查小人是否在线上、进度是否正确变色、图框是否在主体区居中、字幕是否抢跑。

渲染前把每个文字、外框、卡片、按钮、角色和截图框的坐标交给 `src/LayoutGuard.ts`。它会在开发阶段报出安全区溢出或不允许的矩形重叠；不要等成片里出现压字才发现。详细分镜表、画面职责与无意义装饰删除规则见 [director-preflight.md](director-preflight.md)。
