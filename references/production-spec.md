# 制作规范与画面变化库

本规范保留账号做法的制作逻辑，不携带任何品牌素材。使用时替换品牌色、角色、Logo、字体和音色，保留画面层级、时间轴与审片方式。

## 一条视频的基础结构

1. 开头三秒先给观众一个明确收益，再立即落到具体问题或例子；不要一开始连续要求点赞、收藏、关注。
2. 用一个生活任务或真实操作把概念一步步带出来。一个新需求对应一个新概念，不开头堆定义。
3. 白底讲具体场景，黑底讲关系、列表、对比与技术结构。真正换主题时，才插章节页。
4. 一条视频里要有结果、讲解、练习或下一步行动，但不要把所有细节一次说完。

## 画面选择和变化

| 文案工作 | 用什么画面 | 怎么变化 |
| --- | --- | --- |
| 同一生活场景中的一句推进 | 白底人物场景 | 同场景换表情、手势、指向物或镜头轻推，不机械整张换图 |
| 一个到三个短重点 | 白底人物场景 | 大字在安静留白处依次出现；人物和背景不要被文字遮住 |
| 四项以上、定义、步骤、文件夹、选项 | 黑底网格知识卡 | 所有项原位保留，口播说到哪一项就点亮哪一项 |
| 两个概念发生关系 | 黑底网格 | 点先出现，线画出来，再出现中间结果卡 |
| 新的主题 | 黑底章节页 | 小章节号、主标题、短说明依次出现 |
| 搜索、输入、代码、命令 | 黑底终端或搜索框 | 打字机输入，再出现点击或确认状态 |
| 多张内容卡逐步增加 | 黑底卡片轨道 | 第一张进入并停住，横向移位后再加第二张 |
| 软件界面、README、按钮 | 裁切截图 | 只显示相关区域；目标处在裁切画面的中心，外部淡化或局部放大 |

## 布局和居中

- 画面固定分三层：顶部进度条区、主体区、底部字幕区。每一页的主要视觉重量放在主体区中心，不只是标题居中。
- 白底外框和黑底主要图形都要在主体区上下居中；字幕保持在画面底部稳定位置，不能挤压主体区。
- 左右分栏可用，但两侧的面积、对比度和留白要达到平衡。不要出现“左边一张图、右边几块零散文字”的失衡布局。
- 白底图片有粗圆角外框，图片内的文字避开复杂背景；没有清晰留白就切黑底卡。
- 进度条放在白底和黑底的顶部同一高度。直线和每个圆点必须垂直居中对齐，已经过的线段、节点和当前章节用强调色；小人整体位于线的上方，脚底沿线移动，不压章节文字。
- 进度条不是平均速度装饰。章节数据从最终 `timing.json` 的 `chapters` 读取，文案主题、口播片段、画面段落、圆点、线段颜色和小人位置使用同一组 `startFrame/endFrame`。章节时长不同，小人移动距离和停留也按真实帧数发生。小人的步频独立为稳定循环，不能为了赶路线而忽快忽慢。

## 固定章节开幕模板

每次真的切换主题时，使用同一套 1.6 到 2.4 秒的黑底网格章节页：

1. 小字先出现：`第 02 部分 · 02 / 04` 或自定义章节号。
2. 大标题出现：只写本章要解决的核心问题。
3. 一条短说明出现：告诉观众这一章会看到什么。
4. 章节页结束时，进度条节点切换到当前章节，随后进入对应白底或黑底主体场景。

模板组件为 `ChapterTitle`。它只用于真正的章节开幕，不要把普通过渡句也做成开幕页。

## 聚焦与点亮

- 普通列表、选项、文件夹、流程节点：保持原位，依照口播锚点原地变亮，其他项只稍暗。
- 单一截图目标、一个文件、一个按钮或一个必须仔细看的概念：可以中央聚焦。先裁切，再把目标放在框内视觉中心，四周轻微变暗。
- 不要把每个列表项、每个文件夹或每一段话都拉到中央聚焦。聚焦是观察动作，不是常规转场。
- 讲完的重点可轻微变暗，当前重点最清晰；背景网格始终在最底层，不盖住文字和动效。

## 字幕与时间轴

- 字幕按原稿标点和自然语义停顿分段，屏幕中删除 `，。？！`。没有自然停顿时，宁可保留完整词组，不把一个词拆开。
- 字幕从真实 spoken phrase 的开始帧出现；当配音说完对应片段时结束。重新生成 TTS 后，必须同时重新生成字幕、画面 cue 和场景停留。
- 重要内容的高亮、点亮、截图框选、人物动作和音效，都绑定对应词的真实 `startFrame`，不能按场景长度平均分配。
- 字幕使用固定基线和淡入上移。普通字幕清晰易读，重要展示词才使用账号指定字体；不要给每句话都套重点样式。

## 声音、BGM 与审片

- 优先一条完整配音保持情绪一致。分段时按句末分、同音色同提示同语速，重新做真实时间轴。
- 外文技术名保持正确拼写并按原语言发音；上线前抽听所有术语。
- BGM 只做铺底，先以人声音量的 0.5%–2% 试听。听不清辅音就再降。音效只在看得见的点击、点亮、确认、切换动作上出现。
- 每页至少抽看：前一条 cue 前、当前词首帧、下一条 cue 后；再看静帧是否平衡、进度条/小人是否正确、字体有无换行、字幕有无抢跑。

## 不能出现的情况

- 全篇只靠三张图反复切换；也不能每句话都换完整背景。
- 白底图上放四项以上小字，或让文字与复杂背景撞色。
- 使用与口播无关的中间大字充当过渡。
- 重点提前出现，或口播已讲到下一项但画面仍停在上一项。
- 全屏塞入截图；无关区域应裁掉、淡化或留在框外。
