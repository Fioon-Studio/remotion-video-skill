# 知识类视频制作链

本参考把“定稿口播 → 声学对齐 → 导演编排 → 素材 → 样片 → 成片审片”拆成可复核的中间结果。它服务于中文知识视频，不要求一次性无人干预出片。

## 1. 固定顺序与通过条件

1. **输入确认**：口播已定稿，画幅/视觉方向已确认，产品界面、案例、数据和录屏有真实来源。缺失内容写为“待补素材”。
2. **完整配音和对齐**：优先一次生成完整 narration；生成短语级时间线，所有字幕、画面、点亮、截图焦点和音效共用它。
3. **视觉编排表**：先决定每段为什么需要这个画面，再开始生图或编码。
4. **素材准备**：A-roll 管角色与场景一致，B-roll 管真实证据与知识关系。
5. **样片**：45 至 75 秒，必须包含片头、人物、知识卡、截图焦点和行动提示；通过后才做全片。
6. **审片**：每秒一帧审全片；所有锚点验收 `start-1`、`start`、`end-1`、`end` 四帧。

## 2. 配音和声学对齐

`timing.json` 中每段至少包含 `id`、原文、`startMs`、`endMs`、`startFrame`、`endFrame`、章节和无标点字幕文本；`vo-align.txt` 用于快速人工核查。

- 原稿是真值，ASR 只提供时间；识别错字时保留原稿文字。
- 用自然短语切分，通常 5 至 15 个汉字；技术词、产品名和要点词可独立成锚点。
- 相邻项不重叠、不留无意义空档，最后结束时间等于音频总时长。
- 连续英文术语若被合并，截取局部音频重新强制对齐；不得按字符或词数均分时间。

### 提示词：配音和声学对齐

```text
请按顺序完成完整配音与声学对齐；在通过检查前，不要制作画面。

输入：
- 已定稿口播：{script_path_or_text}
- 音色与语速：{voice_setting}
- 目标帧率：{fps}，默认 60

要求：
1. 整段口播一次合成为一条 narration 音频，不要逐句合成后拼接。
2. 输出音频并记录精确总时长（毫秒）。
3. 对最终音频做中文短语级对齐；原稿用于显示文字，识别结果只用于取得时间。
4. 按自然语义停顿切分；英文术语、产品名、需要点亮的要点分别建锚点。
5. 写出 timing.json 与 vo-align.txt。相邻段不重叠，最后结束时间必须等于总时长。
6. 汇报音频路径、总时长、段数、最后结束时间、未可靠识别的词。
```

## 3. 视觉编排表

每个镜头必须先回答：观众要懂什么、为什么是这个画面、主体发生什么有效变化、最后停在哪个结果、怎么进入下一镜。不能因逗号、固定秒数或停顿机械切镜。

| 类型 | 适合内容 |
| --- | --- |
| A-roll 人物/场景 | 情绪、提问、生活例子、章节开场、行动召唤 |
| B-roll 真实素材 | 产品、操作、数据、案例、项目文件 |
| B-roll 信息图形 | 比较、步骤、关系、因果、层级、筛选 |
| 文字动效 | 章节题、金句、极短结论 |

### 提示词：视觉编排

```text
基于已定稿口播和真实时间轴，生成可直接指导素材准备与动画制作的视觉编排表；现在不要生图、写动画或渲染。

输入：
- 口播：{script_path_or_text}
- 时间轴：{vo_align_path_or_text}
- 已有素材索引：{asset_index_path_or_list}
- 账号视觉规范：{brand_or_style_path}

规则：
1. 按完整语义段落理解脚本，不按字数、标点或固定时长切镜。
2. 镜头起止只可取自时间轴的短语边界，不改写时间戳。
3. 每个镜头明确一个理解目标，并选择 A-roll 人物/场景、B-roll 真实素材、B-roll 信息图形或文字动效。
4. 超过约 5 秒的镜头写出与口播对应的有效信息变化；入场、呼吸、背景循环和字幕出现不算变化。
5. 提到真实产品、界面、数据、案例而素材库没有时，标记“待补素材”，不要编造。
6. A-roll 与 B-roll 自然交替；避免连续多镜头使用同一种视角或同一种表达结构。
7. 规划标题、主体、说明、截图焦点和字幕预留区矩形，确保它们不相撞并处于主体安全区。

输出表格：
| 镜头 | 时间 ms / 帧 | 对应口播 | 理解目标 | 画面类型 | 主体与构图 | 有效变化 | 承接方式 | 素材状态 |

最后列出：待补素材、待确认的视觉选择、制作难度高的镜头，以及 A/B 交替检查结论。
```

## 4. A-roll：角色和场景

角色一致性使用本地三类参考：角色正侧背视图、局部风格细节图、场景气质图。可选视角应当服务叙事：主持人用于开场/章节/总结；主角用于生活例子和动作；配角用于补充关系；第一人称用于进入操作或观察目标。

同一场景超过约 5 秒，使用同机位动作一、动作二、动作三推进口播；不要用同一静图拖满，也不要无故换背景。三项以内短信息才可置于安静留白；四项以上转 B-roll。

### 提示词：A-roll 素材

```text
为这个镜头制作 A-roll 素材。先说明理解目标和构图，确认不会与标题、字幕或信息卡冲突后再生成。

本地参考：
- 角色三视图：{character_turnaround}
- 风格细节图：{style_closeup}
- 场景参考：{scene_reference}
- 镜头行：{storyboard_row}
- 视角：{主持人 / 主角 / 配角 / 第一人称}

角色比例、五官、服饰和配色以三视图为准；画风以细节图为准；场景层次与简化程度以场景参考为准。人物、道具、视线和景别服务这句口播；不要把长文字塞进图片。
```

## 5. B-roll：先选关系骨架

先确定语义结构，再选组件或模板。常用结构：比较、聚合、筛选、层级、因果、替换、展开、步骤。按“本地模板 → 已允许的公开模板 → 新建组件”选择；只替换内容和外观，保留最适合的元素关系与阶段顺序。

真实截图或录屏只展示目标区域，目标居中裁切；只讲单一目标时才使用局部压暗、圈选或放大镜。无素材时用信息图形解释关系，纯文字只用于章节或极短结论。

### 提示词：B-roll 模板选择

```text
为这一个 B-roll 镜头选择视觉结构；先给方案，未获确认前不要实现。

镜头：{shot_id}
时长：{duration_ms}
口播：{voice_line}
观众要理解的一句话：{learning_goal}
素材类型：{真实截图或录屏 / 无现成素材 / 纯文字}
语义结构：{比较 / 聚合 / 筛选 / 层级 / 因果 / 替换 / 展开 / 步骤}
本地模板索引：{template_index}
可用公开模板来源：{approved_sources}

步骤：
1. 优先检查本地模板；没有合适项才检索允许的公开来源。
2. 说明保留的骨架：元素关系、主要动作、阶段顺序。
3. 说明仅替换的内容：文案、颜色、字体、Logo、截图和品牌元素。
4. 写出每个口播锚点对应的出现、点亮、转场或结果状态，并说明截图目标怎样置于裁切框中央。
5. 检查主内容是否在安全区居中、文字与外框是否相撞、每个元素是否有讲解职责。
```

## 6. 审片回路

每次发现问题，记录“现象 → 对应的时间锚点/规格字段/矩形 → 修复 → 复验帧”。不要在组件中用任意负位移、额外延迟或单独补帧掩盖问题；回到规格或时间轴修正后再渲染。
