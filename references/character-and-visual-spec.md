# 主角 IP 与画面规范

## 先做角色母版，再做视频

每个账号先建立一个可长期复用的主角 IP。角色不是一张“好看的单图”，而是一套可以持续出现在不同场景中的视觉身份。

将 `config/character.example.json` 复制为本地 `character.json`，并根据它制作自己的私有角色素材。公开仓库只保留 JSON、占位文件名和制作说明，不上传真人照片、品牌角色、商用角色素材或原始 Logo。

### 角色母版必须包含

| 类别 | 最低要求 | 为什么 |
| --- | --- | --- |
| 视图 | 正面、左前 45 度、侧面、背面 | 新场景和行走动作不会突然换脸或换比例 |
| 身份锚点 | 发型、发色、瞳色、固定服装、1–2 个饰品 | 一眼认出是同一账号人物 |
| 表情 | 平静、讲解、思考、惊讶、开心 | 同一场景可用表情推进文案，不必每句切图 |
| 动作 | 左右指向、摊手、打字、举卡片、庆祝 | 能覆盖教程、举例、列点和结尾 |
| 行走 | 6 帧左右、透明底、同尺寸同侧视角 | 可放在章节进度条上无缝循环 |
| 场景 | 书桌、白板、电脑、手机、资料卡等常用环境 | 每次新增画面仍可保持角色和构图稳定 |

### 生成角色图的要求

- 先制作一张角色设定图，四个视图放在同一张画布中，身高、头身比、服装、饰品完全一致。不能用四张随机单图代替。
- 每个动作都引用同一份角色设定图。先确认姿势，再生成场景；场景里的人物和环境应同时生成或一起重绘，避免机械地把抠图人物贴到背景上。
- 行走帧从同一个侧视角生成，背景透明或单一可抠底色。第一帧和最后一帧腿部位置必须能自然接回。
- 每次新生成角色素材后，检查脸型、衣服标识、发型、手指数量、鞋子和比例。任一身份锚点漂移，就不要混入素材库。

## 画面规范

### 全片稳定元素

- 顶部：Logo 或项目标识、章节进度条、行走主角。白底和黑底位置保持一致。圆点中心与直线中心严格对齐；主角在直线上方行走，脚底沿线但不穿线。
- 中间：主体区。标题、图片、截图、关系图、卡片的总视觉重量在这里平衡。
- 底部：字幕区。基线固定，和主体留出呼吸距离；不把字幕贴在图片边缘。
- 整条视频统一：圆角、边框粗细、强调色、普通字体、重点字体、阴影强度和动效速度。

### 白底人物场景

- 使用暖白或低饱和浅色底，图片放在比画布小一圈的粗圆角框中。框外留白和框内构图都要干净。
- 主角、环境和关键道具在一张画面中形成自然场景。前景可鲜明，后景色彩淡一些，文字落在背景最简单的区域。
- 同一场景优先换动作或表情：指向屏幕 → 思考 → 庆祝；有新地点、新任务或新道具才换完整场景。
- 图片内的文字限制为一到三个短重点。关键字大、对比高、避开人物脸和复杂背景；大标题、四项以上列表、长解释都放黑底。

### 黑底知识卡

- 纯黑或近黑底，网格铺满最底层，网格低对比，不能压到文字、线条和卡片上。
- 画面主体在中间区域，不把卡片、标题和关系图整体挤到左上。
- 主标题只在需要总结时出现，重点词大而清晰；普通解释字低一级。不要突然在图片中间插入一条无关大字。
- 当前项最亮，讲完项略暗，未讲项可见但次要。每次只发生一种主要变化，例如点亮、连线、拉出卡片或打字。

### 截图与真实界面

- 有真实界面时优先用真实截图，且使用中文界面；不要为了省事画一个假 Logo 或替代界面。
- 从截图中裁出任务相关部分，放进同样的圆角框。README、按钮、文件名等目标在框选区域的中心。
- 需要强调时用框选、轻微变暗和局部放大；不用全屏截图堆满画面，也不让框选目标贴顶部。

### 字体与颜色

- 重点展示字使用账号已经授权的重点字体；普通说明和字幕使用清晰、稳定的系统字体。
- 重点字不需要底部色块。白底优先深色字，黑底优先白字，强调色只给当前重点、进度和确认状态。
- 字号先保证能读，再决定页面类型。任何文字需要缩小到难读，说明应该切黑底或拆页。

### 不同画幅

- 先确定目标画幅，再排版，不要把横版画面硬裁成竖版。
- 所有画幅都保留顶部导航、主体区和字幕区。竖版扩大纵向留白，横版增强左右平衡。
- 封面单独排版：一句大标题、一个清晰主角或主物、少量辅助字；不要把视频截图直接当封面。

## 入库前验收

1. 把角色母版、表情、动作、行走帧和常用场景放入“角色素材库”，按角色 ID 和动作命名。
2. 在新视频首帧、中段、结尾各抽一张图，确认主角身份锚点没有漂移。
3. 检查白底框、黑底网格、进度条、字幕区、字体和强调色是否保持同一套规则。
4. 只把验收通过的素材标为可复用；失败图另存，不要混进可调用目录。
