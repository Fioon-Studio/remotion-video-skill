# TTS、音效与替换选项

## 配音选择

先生成一条完整试听，再决定是否分段。长音频通常更容易保持前后情绪一致；必须分段时，每段使用同一个音色、相同风格描述、相同语速，并在句号处切开，最后按真实音频重新对齐。

| 方式 | 适合情况 | 使用方向 |
| --- | --- | --- |
| 已授权的自定义音色 | 已有可用样本，希望保持声音一致 | 在本地保存样本和 API 配置，不提交到仓库 |
| 云端 TTS | 想快速开始、音色稳定 | 选择支持中英文混读的音色；英文技术名保持原拼写并单独试听 |
| 本地 TTS | 需要离线或控制成本 | 先确认中文自然度与英文术语发音；不把模型权重放进仓库 |
| 剪辑软件配音 | 想少配置 API | 用它生成完整音频，再导出 WAV/MP3 进行时间轴对齐 |

## 语气与语言

- 写给 TTS 的说明只写表演需求，例如“自然、有分享欲、语速中等、在新章节前停半拍”。不要把整套制作规范塞进配音文本。
- `LLM`、`Agent`、`Workflow`、`Tool`、`Memory`、`Skill`、`TTS` 维持英文原文。生成后抽听所有术语；读错时只重录对应完整句，再重新做 timing。

## 音乐和音效

- BGM 是衬底，默认从人声的约 0.5% 到 2% 音量开始试听，再按实际配音调整。
- 转场、点亮、确认和点击音效只在画面出现对应行为时触发，且低于人声。
- 可以使用用户已授权的剪辑软件曲库，或确认许可允许商用的音乐库。下载来源和许可证单独保存，不提交到公开仓库。
